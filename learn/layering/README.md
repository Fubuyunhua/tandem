# 分层练习：函数式内核 + 命令式外壳

同一个功能，两种写法：
> CI 跑完后：绿了就结束；红了就重试，最多 2 次；还不行就找你。
> 静默时段（23:00–08:00）只推送 D 级，其余放进明早摘要。

| 文件 | 作用 |
|---|---|
| `world.py` | 模拟外部世界：网络、手机、日志、时钟、随机数 |
| `mixed.py` | 写法 A：判断和执行混在一起 |
| `core.py` | 写法 B 的内核：只做判断 |
| `shell.py` | 写法 B 的外壳：只做执行 |
| `test_core.py` | 内核的测试，外加一个"边界守卫" |

所有命令都在本目录下运行（`learn/layering/`）。

## 练习

**1. 观察。** 把下面两条命令各运行两三次：
```
python mixed.py
python shell.py
```
两者的输出几乎一样。但因为 CI 结果是随机的，每次运行的输出都不同。

**2. 跑测试。**
```
python -m unittest -v
```
9 个测试应该全部通过，用时不到一秒。

然后想一想：**`mixed.py` 要怎么测？** 尝试写一个测试，验证"凌晨 3 点不推送 C 级"。

**3. 改规则：静默时段从 22:00 开始。**
- 在 `mixed.py` 里改一次。注意你得在一整段流程里找到那个数字。
- 在写法 B 里按测试优先的顺序改：
  1. 先在 `test_core.py` 里加一个"22 点不推送 C 级"的测试；
  2. 运行测试，看它**失败**；
  3. 再去改 `core.py`；
  4. 再运行测试，看它通过。

**4. 改规则：D 级不重试，直接找你。**
- 提示：`after_ci` 需要知道级别，所以要多一个参数。改完参数之后，外壳里调用它的地方也要跟着改。
- 想一想：这次改动，哪些在内核，哪些在外壳？

**5. 思考题：把飞书换成 Telegram。** 两种写法各需要改哪些文件？你的判断规则会不会被碰到？

**6. 搞破坏：** 在 `core.py` 顶部加一行 `import datetime`，再运行测试，看"边界守卫"会怎么报错。

做完以后删掉这一行，并用一两句话写下：你觉得分层的**好处**和**代价**各是什么。这就是 ADR-001 "问题 1" 的素材。
